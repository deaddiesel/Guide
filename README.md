<td valign="top" align="left" width="78%" style="width:78%;">
<p>▸ <b>Four Tabs, One Screen:</b> A single 560×340 screen with a sidebar of tabs and a book selector at the top. Icon, Cursor, Theme and Background are all editable in place.</p>
<p>▸ <b>Icon Tab:</b> Pick from 5 item presets (<code>minecraft:book</code>, <code>writable_book</code>, <code>enchanted_book</code>, <code>knowledge_book</code>, <code>written_book</code>) or from a gallery in <code>config/guide/user/icons/</code>. Any image size is accepted — large images are downscaled to fit the slot with aspect preserved; small icons stay at native size and are centered.</p>
<p>▸ <b>Cursor Tab:</b> Full cursor editor with live preview. Files come from <code>config/guide/user/cursors/</code> (PNG, JPG, JPEG, BMP). Cycle scale 1×–4×, set hotspot to Center or manual X/Y. The tab shows exactly which source is in effect — <code>book.json → file</code>, <code>user → file</code>, <code>global → file</code> or <code>default</code>.</p>
<p>▸ <b>URL Downloads:</b> Both Icon and Cursor tabs ship with a URL field and a <b>Download</b> button. Files are fetched through <code>MediaDownloadManager</code>, validated by magic bytes, and saved into the same user folders as manual drops. Status is shown directly in the button label.</p>
<p>▸ <b>Live Application:</b> Every change in the Cursor tab — picking an image, cycling scale, toggling Center, editing X/Y, downloading from URL or pressing Reset — applies to the actual mouse cursor immediately, without closing the screen.</p>

<p>▸ <b>Command-Driven:</b> <code>/guide unlock &lt;tag&gt;</code> and <code>/guide lock &lt;tag&gt;</code> grant or revoke tags; both accept an optional player argument (OP level 2) for admins. <code>/guide unlocks</code> lists your active tags, <code>/guide unlocks clear</code> wipes them all at once.</p>
<p>▸ <b>Modpack-Friendly:</b> Any system that can dispatch a command works — KubeJS events, FTB Quests rewards, advancements, or custom script packs. State is stored per-player in server-side NBT and synced on login and after every change.</p>

<p>▸ <b>Per-Book Overrides:</b> Five optional fields in <code>book.json</code>: <code>cursor</code>, <code>cursor_selector</code>, <code>cursor_diary</code>, <code>cursor_scale</code> (1–4 or 0 to fall back to UI), <code>cursor_hotspot</code> (<code>"center"</code> or <code>"x,y"</code>). Every note holds a title, a body, a creation / update timestamp, and the coordinates + dimension where it was created. <p>▸ <b>Interactive Checklists:</b> Markdown-style checkboxes (<code>- [ ]</code> / <code>- [x]</code>) toggle on left-click inside the preview. State is stored inside the note itself and saved on every click. Completed tasks show a green checkmark and a strikethrough.</p>
<p>▸ <b>Network Sync:</b> Two payloads keep the journal in sync — a sync payload (server → client, sent on login) and an update payload (client → server, sent on create / update / delete). Last-write-wins conflict resolution, no confirmation roundtrip.</p>

<pre><code>📄 Example book.json:

{
  "name": "&lt;book_id&gt;.book.guide",
  "namespace": "&lt;book_id&gt;",
  "default_chapter": "introduction",
  "icon": "your_logo.png",
  "bg_music": "background_music",
  "theme": "&lt;theme_id&gt;",
  "dev_only": false,
  "index": 0,
  "unlock_tag": "",
  "cursor": "",
  "cursor_selector": "",
  "cursor_diary": "",
  "cursor_scale": 0,
  "cursor_hotspot": ""
}</code></pre>

<sub>▸ <code>index</code> is optional. Books are sorted by it in the selector (lower = earlier). Books without <code>index</code> fall to the end, sorted by namespace.</sub>

<sub>▸ <code>unlock_tag</code> is optional. Leave it empty to keep the book public; set a tag (e.g. <code>"secret"</code>) to hide the book until the player receives that tag via <code>/guide unlock secret</code>. Tags are per-player and persist across sessions.</sub>

<sub>▸ <code>cursor</code>, <code>cursor_selector</code>, <code>cursor_diary</code>, <code>cursor_scale</code> and <code>cursor_hotspot</code> are optional. Set them to force a specific cursor for the book, the book selector and the diary screens. Leave empty to fall back to the player's choice (UI → global → default). See <a href="THEMES.md"><code>THEMES.md</code></a> for the cursor file format.</sub>

<img src="https://capsule-render.vercel.app/api?type=rect&color=gradient&customColorList=6,11,20&height=70&section=header&text=Themes%20and%20Cursor%20Format&fontSize=36&fontAlign=50&fontAlignY=58" width="100%" alt="Themes and cursor format section"/>

<div align="center">

<p>Every UI element is themeable via JSON. Custom themes live in <code>config/guide/themes/</code> — copy the template, tweak the colors, save as a new file.</p>

<p>Each theme can also define its own <b>chapter background</b> — a solid color or an image that replaces the default background for every chapter in books using this theme.</p>

<p>📖 <b>Full theme JSON reference, color format table and cursor file format:</b> see <a href="THEMES.md"><code>THEMES.md</code></a>.</p>

<p><b>Colors are written in <code>0xAARRGGBB</code>:</b> <code>AA</code> = alpha (00–FF), <code>RR</code>/<code>GG</code>/<code>BB</code> = red / green / blue channels. Set alpha below <code>FF</code> (e.g. <code>80</code>) to make panels semi-transparent.</p>
