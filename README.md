<pre><code>config/guide/books/&lt;book_id&gt;/
├── chapters/           # Content sections
│   ├── index.md        # Primary index
│   ├── introduction.md # First chapter
│   └── &lt;language&gt;/     # Language-specific files
├── lang/               # Localization
│   ├── en_us.json
│   └── &lt;language&gt;.json
├── models/             # 3D model data
├── sounds/             # Background audio (.ogg)
├── videos/             # Local video files
├── textures/           # UI and image assets
├── structures/         # Multi-block .nbt blueprints
└── book.json           # Metadata</code></pre>

<pre><code>📄 Example book.json:

{
  "name": "&lt;book_id&gt;.book.guide",
  "namespace": "&lt;book_id&gt;",
  "default_chapter": "introduction",
  "icon": "your_logo.png",
  "bg_music": "background_music",
  "theme": "&lt;theme_id&gt;",
  "dev_only": false
}</code></pre>
